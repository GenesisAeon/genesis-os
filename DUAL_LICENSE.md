## Feldtheorie Integration

Code integrated from the Feldtheorie repository
(https://github.com/GenesisAeon/Feldtheorie, GPLv3 + CC BY-NC 4.0)
is included under the same GPLv3 terms, consistent with both repositories
being authored by Johann Römer (GenesisAeon), who holds copyright over
both. The data and content from Feldtheorie retain CC BY-NC 4.0 where
indicated; the genesis-os documentation and notebooks are CC BY 4.0.

Integrated Feldtheorie components:
- `src/genesis_os/core/utac_bridge.py` — UTACBridge (β-domain registry)
- `src/genesis_os/afet/` — AFET field entropy module
- `src/genesis_os/core/crep_engine.py` — Enhanced CREP empirical metrics
- `src/genesis_os/aeon/` — Nullkern, AeonShell, SemanticAgent, LanternNet
- `src/genesis_os/vrig/` — v_RIG Fisher-Rao velocity framework
- `src/genesis_os/science/` — Empirical β-fitting pipeline (78 systems)
- `src/genesis_os/sigillin/` — Trilayer synchronization protocol

## Mathematical Content Notice

The β-domain clustering values (informational β≈4.5, biological β≈7.4,
climate β≈11.0, neurodegen β≈13.0) and the ANOVA result
F(4,73)=185.3, p<1e-20, η²=0.91 are derived from Feldtheorie's analysis
of 78 published systems. The v_RIG constant (~1351.8 km/s) and the 13.5 MHz
LanternNet frequency are research hypotheses, not verified physics.
